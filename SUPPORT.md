# Support

## Data, metrics and dashboards

For questions about data, metrics, dashboards, or a suspected data-quality issue, use the **data support intake**: open a request in [`data-support-requests`](https://github.com/swapfiets-tech/data-support-requests/issues/new/choose), or ask in the data support Slack channel. An analyst triages these daily and routes them to an owner.

Include the dashboard or metric, the domain, what you expected versus what you saw, and how urgent it is.

## Access

Request access to tools (Snowflake, dbt Cloud, Tableau, and similar) through AccessOwl in Slack.

## Bugs and feature requests in a specific repository

Open an issue in that repository using its bug report or feature request form.
