# Contributing

These conventions apply across Swapfiets' Data & AI repositories.

## Pull requests

1. Branch off the default branch.
2. **Open your PR as a draft first.** Mark it "Ready for review" only when you actually want review, so CODEOWNERS are not notified and the full CI suite does not run while you are still iterating.
3. Fill in the pull request template: what changed, why, and how you validated it.
4. Keep PRs focused and reasonably small.
5. We squash-merge, so the PR title becomes the commit message. Make it clear and descriptive.

## Reviews

Pull requests require review before merging. Code owners (see each repo's CODEOWNERS) are requested automatically.
